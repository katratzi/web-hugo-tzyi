I've been giving Folios a little attention for v8, smoothing out a few rough edges and adding some everyday conveniences. You can now select and delete several photos together while editing an album, making it a little easier to tidy up your collection.

I've also fixed how editing tags works from the main album view. If a tag belongs to only some photos, saving your changes now preserves that selection unless you explicitly change it. Consistent icons (circle, semicircle and cross) make it clearer which tags apply to all, some or none of the photos.

Tag albums should feel more responsive too. There's also a fix for a crash involving deleted photos or tags. Enjoy the update!
