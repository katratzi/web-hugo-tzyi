This release (v7) makes it easier to reorganise your library.  You can now merge albums and move images around.  There's a bug fix for Mac too: the edit tags popup now scrolls.  There are also a handful of little tweaks, like clearer wording on some features and better alerts for deletion.  

I've also added a little animated iCloud icon to the main view.  For those interested, the app uses SwiftData from Apple, which makes syncing across devices work automagically.  Its main weakness is that there isn't much information available through the API. The icon simply lets you know that iCloud is happily working away in the background.  It's a handy little reassurance that everything is still syncing and probably just needs a bit more time.
