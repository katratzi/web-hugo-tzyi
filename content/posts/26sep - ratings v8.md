Version 8 - You can now export a folder as CSV or JSON and import it back into Ratings. CSV is handy for spreadsheets, while JSON includes your images too, making it the more complete backup option. Before importing, the app checks the file and shows you how many ratings it contains. It keeps your existing ratings, so importing the same file twice will add duplicates.

If you fancy a clean slate, **long-press** to find the administration screen and its new delete all data option. There's a confirmation before anything is removed, but this does clear every folder and rating, including their images, and syncs those deletions to your other devices through iCloud. 

{{< figure align=center src="/ratings/releases/v8 admin.jpg" title="Long press the settings button to find the admin panel." >}}

There are a few smaller quality of life changes too: tap your current sorting option again to reverse its order, and a little pulsing cloud now lets you know when iCloud is working away in the background. Plus a bug fix on how empty ratings are removed when you close the editor.  Check out (v8) on the app store now :)
